Entry for the make.fun competition
[make-the-ai-judge-feel-curious-20261122-2311](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311):
a single short text (240 characters) written to make the AI judge feel
curious. A book comes back to the library forty years overdue — no fine, no
name — but its last page, blank since printing, is now full of handwriting
that begins in the middle of a sentence.

## Run

```bash
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, no trailing
newline).
